# Signaler une faille de sécurité

Relève traite des données fiscales de clients. Si vous découvrez une faille (fuite de données, envoi non prévu vers l'extérieur, action non souhaitée sur le site des impôts, contournement d'une règle de conception…) :

- **ne la décrivez pas dans une issue publique** ;
- signalez-la en privé avec le bouton **« Report a vulnerability »** de l'onglet **Security** de ce dépôt.

Indiquez la version concernée, ce que vous avez constaté et, si possible, comment le reproduire avec des données fictives. Une réponse est apportée dès que possible ; la correction est publiée avant toute description détaillée de la faille.

Seule la dernière version publiée sur le site officiel (https://releveavis.netlify.app) est maintenue.
